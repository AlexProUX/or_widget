# OpenRouter Widget for macOS

A compact menu-bar widget for browsing discounted, popular, and newly released
OpenRouter models. Clicking a model copies its provider path in the form
`openrouter/provider/model`.

## Requirements

- macOS 13 or later
- Apple silicon Mac

## Install

1. Download `OpenRouterWidget.app.zip` from the latest GitHub Release.
2. Double-click the archive to extract `OpenRouterWidget.app`.
3. Move `OpenRouterWidget.app` to the `Applications` folder.
4. On first launch, Control-click the app and choose **Open**. If macOS still
   blocks it, open **System Settings → Privacy & Security**, choose
   **Open Anyway**, and confirm.

The app runs only in the menu bar and does not appear in the Dock. Left-click
the OpenRouter icon to open the widget. Right-click it to see the installed
version, install an available update, or quit the app.

## Updates

The widget checks GitHub Releases when it starts and every three hours. When a
new version is available, select **Update** in the status-item menu or click the
orange **Update** button in the widget.
